# Published results

`published_sb_piplu_results.csv` contains the Sb-PiPLU rows from Tables 2–6 of
the IEEE Access article. Values are copied with the same two-decimal precision
used in the tables.

For SVHN with AlexNet, Table 5 reports an overall accuracy of `91.14%`. The
surrounding paragraph gives a conflicting value, so the table value is used in
the CSV.

`published_k_initialization_summary.csv` contains only the five peak
accuracies stated in the text for the `k = 21` experiment in Figure 3. The
remaining points are not read from the plot.

Figures 4 and 5 do not provide the underlying runtime and epoch values as a
numerical table. No values are estimated from those figures.
